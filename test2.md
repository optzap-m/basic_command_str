ЗАПУСК ПРОГРАММЫ
Greeter — простое приложение, которое должно печатать на экран приветствие Hello, Hexlet! It works!. Но сейчас при запуске оно выводит на экран неинформативное сообщение Something went wrong.

В этом испытании вам нужно будет разобраться и отладить приложение greeter. Задача будет считаться выполненной, когда вывод команды

greeter
станет таким:

Hello, Hexlet! It works!
Подсказки
Для того чтобы вывести справку, наберите команду greeter -h
Код приложения исправлять не нужно, причина ошибки в его настройке. Подробное сообщение об ошибке приложение печатает в режиме отладки, который включается опцией из справки
Сообщение ENOENT: no such file or directory означает, что файла по указанному пути нет. Такой файл нужно создать, и права суперпользователя для этого не нужны
Для создания и редактирования файла конфигурации используйте редактор nano или vim

Решение:
1. Выводим greeter -h, и видим наличие флага --debug
2. Запускаем с флагом --debug, получаем информацию, что нет файла
3. Создаем файл, вписываем содержимое
4. Вы великолепны
